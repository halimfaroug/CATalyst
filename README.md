# CATalyst Academy - ENGL465 Interactive CAT Learning Platform

A single-file, interactive educational platform for **Computer-Assisted Translation (CAT)** learning.  
Built from the attached **ENGL465 course topics**, it combines theory, revision, source-based practice, gamified learning, glossary building, and progress tracking in one browser-ready file.

---

## 🎯 Overview

CATalyst Academy is designed as an interactive study hub for ENGL465 students.  
It transforms course materials into:

- **Topic explorer cards**
- **Flashcards**
- **Quizzes**
- **Mind maps**
- **Gamified learning challenges**
- **Glossary and term-extraction activities**
- **Progress analytics**
- **Source explorer with course references**

The platform uses a **single HTML file** and runs directly in the browser with no framework or installation required.

---

## ✨ Features

### Interactive Learning
- **11 topic modules** based on the attached ENGL465 materials:

  - Topic 2: The Translator’s Workstation
  - Topic 3: Translation Memory Systems
  - Topic 4: Terminology Tools for Translators
  - Topic 5: Localization & Translation

  - Topic 7: Corpora & the Translator
  - Topic 8: Why Translation is Difficult for Computers
  - Topic 11: How to Evaluate Machine Translation
  - Topic 12: Sublanguage
  - Topic 13: Post-Editing

- **Source-based flashcards**
- **Topic-based and mixed quizzes**
- **Interactive mind maps for each included topic**
- **Weak-area review**
- **Search across topics, cards, and quizzes**

### Practical Learning Tools
- **Glossary builder**
- **Simple term-extraction lab**
- **Source explorer linked to the attached PDFs**

### Gamified Learning
- **XP system**
- **Coins**
- **Levels**
- **Streak tracking**
- **Badges / achievements**

- **Rapid Match mini-game**

### Interface & Experience
- **Single-file HTML platform**
- **White, readable academic interface**
- **Kermit SemiBold support** (optional local font file)
- **Moving catalyst-style animated background**
- **Serene study music** (optional MP3, with fallback ambient audio)

1. Download or save the file as `index.html`
2. Open it in any modern browser
3. Click **Enter Platform**
4. Start learning
